Phase 1 Features

What goes live in the web portal first.

The Phase 1 web portal includes everything an owner needs day-to-day, deployed quickly and built on widely-supported infrastructure so we can iterate fast based on real owner feedback.

  • Property DashboardSummary of status, last visit, upcoming visits, and any open issues.
  • Inspection Reports with PhotosEvery walkthrough produces a photo-documented report visible the moment our crew uploads it.
  • Work Order ApprovalsEstimates over your set threshold show up here for one-click approve / decline.
  • Service Request SubmissionNeed something done? File a request right from the portal — your manager sees it instantly.
  • Invoice HistorySee every Red Turtle invoice, what it covered, and whether it's been paid. Export to PDF for your accountant.
  • Document VaultProperty records, service contracts, warranty docs, photos — all searchable, all backed up.
  • Direct MessagingSend a message to your property manager directly. No phone tag, no waiting on hold.
Stack

Built on proven, low-cost infrastructure

Targeting Q3 2026 launch
  • Frontend: Next.js + React, hosted on Vercel
  • Database & Auth: Supabase (Postgres + magic-link auth)
  • File storage: Supabase Storage for inspection photos & docs
  • Email/SMS: Resend + Twilio for notifications
  • Payments: Stripe for invoice payment (when added)
  • Estimated dev: 8–12 weeks to MVP
  • Estimated ongoing cost: ~$120–200/mo at launch scale
Phase 2 Concept · Mobile App

A mobile app for the same data.

Once the web portal is live and we've learned what owners actually use, we build a native iOS / Android app on top of the same backend. Push notifications, one-tap approvals, photo browsing — built for the phone.

Concept only at this stage. We'll revisit timing once Phase 1 has been in real-world use for a few months.

  • Push NotificationsStorm alerts, work-order approvals, urgent issues — right to your phone.
  • One-Tap ApprovalsApprove work orders from the lock screen without opening a browser.
  • Photo BrowsingSwipe through inspection photo galleries with native gestures.
  • In-App ChatReal-time messaging with your property manager.
